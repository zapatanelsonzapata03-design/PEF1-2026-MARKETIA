# Auditoría del cuestionario de aprobación

**Base de revisión:** Cuestionario de Aprobación del Proyecto - Programación II,
adjuntado por el equipo; revisión contrastada con los archivos presentes en el
repositorio.

**Criterios de estado**

- **Parcial:** hay una descripción general, pero falta evidencia, detalle o
  decisión verificable.
- **Pendiente:** no se encontró respaldo suficiente en el repositorio.
- **No evaluado:** requiere ejecutar pruebas o recopilar información que aún
  no existe.

Esta matriz identifica trabajo pendiente; no declara que el proyecto haya sido
aprobado. Las propuestas nuevas deben ser confirmadas por el equipo y el
docente.

pendientes y no puede afirmarse que el proyecto ya cumpla los requisitos de
aprobación.
